StrokeSync — 板绘笔记阅读端

电脑 Obsidian 里写的笔记，通过 Git 自动同步到 GitHub 仓库，
这个页面把仓库里的 Markdown 渲染出来，方便你在 iPad 上随时翻看复习。

开始使用：点右上角 ⚙️ 填入你的仓库名。

⚙️ 仓库设置

⚠️ Token 只保存在本机浏览器里，绝不上传；但仍建议用只有 read 权限的 fine-grained token。私有仓库（Private）必须填 Token，否则会报 404；公开仓库请留空。
📖 怎么把 Obsidian 笔记同步到这里？（一次配置，以后全自动）
  1. 准备两个仓库：公开仓库（如 StrokeSync，放本页面 + 开 Pages）和笔记仓库（放 .md，公开或私有均可）。⚠️ 免费账号的私有仓库开不了 Pages，所以页面要放公开仓库。
  2. 把本页 index.html 放进公开仓库根目录 → Settings → Pages → Deploy from a branch → main / / (root)。
  3. 电脑 Obsidian 安装社区插件 Obsidian Git；把笔记仓库 clone 到任意文件夹，再用 Obsidian「打开文件夹为仓库」。
  4. 插件设置里建议：Push 间隔 5 分钟，启动时自动 pull + push，关闭时自动 push。
  5. iPad Safari 打开 Pages 网址 → 分享 → 添加到主屏幕；⚙️ 里填笔记仓库的 用户名/仓库名，私有仓库再填一个只读 Token。
  6. 以后：电脑上写完笔记，插件几分钟内自动 push → 刷新本页面即可看到最新版。
